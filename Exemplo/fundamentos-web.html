Por que isso importa

      
O que a base te dá — e todo framework empresta dela


      

        

          semântica
          
Marcação que qualquer navegador entende

          
<section>, <button>, <label> já carregam significado, acessibilidade e comportamento — sem uma linha de JS.

        

        

          layout
          
Grid e Flexbox resolvem 90% dos casos

          
A maioria dos layouts que hoje viram "componente de framework" é só um display: grid bem pensado.

        

        

          interatividade
          
O DOM já é reativo — você só precisa ouvir

          
addEventListener, classList e querySelector cobrem acordeões, abas, temas e formulários reais.

        

        

          performance
          
Zero build, zero bundle, zero espera

          
Sem npm install, sem webpack, sem hidratação. O navegador lê o arquivo e pronto.

Abas de conteúdo

            
          

          

            
            
            
          

          
Estrutura o conteúdo e o significado. É a única camada que existe mesmo sem CSS ou JS carregarem.

          
Descreve a apresentação. Um bom CSS resolve responsividade, tema e movimento sem tocar em JavaScript.

          
Adiciona comportamento sob demanda. Aqui: trocar a classe "active" ao clicar — é só isso.

          
botoes.forEach(b => b.addEventListener("click", () => {
  ativarPainel(b.dataset.tab);
}));
